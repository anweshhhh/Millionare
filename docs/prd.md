# PRD — Millionaire: Mind Reader Mode

## Product vision
Build a premium quiz game inspired by KBC / Who Wants to Be a Millionaire where the experience feels personalized, psychologically sharp, and replayable.

The product should feel like it is quietly studying the player:
- confidence
- hesitation
- topic mastery
- pressure response
- overconfidence
- weak-spot patterns

## Product promise
A player should feel:
- this is intense
- this is polished
- this game understands me
- I want one more run

## Core fantasy
A high-stakes hot-seat quiz show where the game adapts to how the player thinks under pressure.

## Target first platform
Web, mobile-first.

## Non-goals for early phases
- multiplayer
- social/community features
- creator marketplace
- user-facing AI chat assistant
- native mobile app
- broad educational LMS features
- broad quiz authoring platform

## Phase 1 objective
Prove that the core millionaire-style gameplay loop is compelling without needing advanced AI.

## Phase 1 scope
- entry screen
- hot-seat game screen
- question presentation
- 4 answer options
- timer
- money ladder
- answer lock-in
- correct / incorrect reveal flow
- game-over / result flow
- polished visual tension

## Phase 2 objective
Add user persistence and run history.

## Phase 3 objective
Add player modeling and adaptive question selection.

## Phase 4 objective
Add post-game insight summaries and private creator analytics.

## Experience principles
- mobile-first
- premium, dramatic, clean
- high visual contrast and focus
- minimal clutter
- fast start
- replay-oriented
- personal without feeling unfair

## AI principles
- AI should support personalization, not dominate the UI
- adaptation must feel fair
- insights must feel specific and earned
- AI should improve retention and player self-understanding

## Success criteria
Early success is:
- the first playable loop feels memorable
- repeated runs feel desirable
- the product looks portfolio-worthy
- the personalization layer is clearly differentiated from generic quiz apps
